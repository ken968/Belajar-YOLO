# Belajar YOLO

Projek latihan deteksi objek menggunakan YOLOv11 dan Python.

## Fitur
- Deteksi objek dari YouTube stream menggunakan `yt-dlp`.
- Integrasi dengan model YOLOv11 (Ultralytics).

## Cara Penggunaan
1. Install dependencies:
   ```bash
   pip install ultralytics yt-dlp
   ```
2. Jalankan script `yt.py`:
   ```bash
   python yt.py
   ```
